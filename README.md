# 🧮 Calculadora Trabalhista

Portal completo com **13 calculadoras trabalhistas e financeiras** atualizadas com as tabelas oficiais.

## 📊 Calculadoras disponíveis

| Calculadora | Descrição |
|-------------|-----------|
| 💰 Salário Líquido | INSS progressivo + IRRF com isenção até R$5.000 |
| 📄 Rescisão | 4 tipos de rescisão + aviso prévio proporcional |
| ⏰ Horas Extras | 50%/100% + DSR + adicional noturno |
| 🔄 Escala 6x1/5x1 | Comparativo entre regimes de trabalho |
| 🏖️ Férias | 1/3 constitucional + abono pecuniário + dobra |
| 🎄 13º Salário | 1ª e 2ª parcela com descontos |
| 🛡️ Seguro-Desemprego | Faixas oficiais MTE |
| 🏦 FGTS | Depósitos + multa 40%/20% + rendimento |
| ⚠️ Adicionais | Insalubridade e periculosidade |
| 📅 Aviso Prévio | Proporcional (30 a 90 dias) |
| ⚖️ CLT vs PJ | Comparativo com Fator R e Simples Nacional |
| 🧑‍💻 Freelancer | Cálculo de valor hora |
| 🏠 Financiamento | Comparativo PRICE vs SAC |

## 🚀 Tecnologias

- **Frontend**: HTML5, CSS3, JavaScript (vanilla)
- **SEO**: Meta tags dinâmicas, sitemap.xml, robots.txt
- **Anúncios**: Google AdSense (3 blocos)
- **Analytics**: Google Analytics 4
- **Deploy**: Render (CD automático via GitHub)
